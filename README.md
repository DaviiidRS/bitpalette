# BitPalette:

BitPalette es una plataforma de gestión y difusión de arte digital. Diseñada para ofrecer una experiencia reactiva, permite a los artistas subir sus obras, interactuar con la comunidad y recibir notificaciones en tiempo real mediante una arquitectura de software desacoplada y robusta.

---

## Requisitos Previos

* **Java Development Kit (JDK):** Versión 22 o superior.
* **Apache Maven:** Versión 3.9 o superior.
* **Navegador Web:** Chrome, Edge o Firefox (actualizados).

---

## Instalación y Configuración

### 1. Clonar el repositorio
```
git clone https://github.com/DaviiidRS/bitpalette
```

### 2. Iniciar el servidor
Ejecuta la aplicación utilizando el plugin de Spring Boot:
```
mvn spring-boot:run
El servidor iniciará por defecto en el puerto 8080.
```
### 3. Iniciar el servidor
Acceso: Abre tu navegador y dirígete a: 
```
http://localhost:8080
```
### 4. Navegación

- Login: Ingresa tu nombre de artista para habilitar la sesión.

- Exploración: Usa el panel central para subir una imagen (puedes arrastrar y soltar el archivo).

- Dale un título a tu obra y haz clic en Publicar.

- Observa cómo la campana de notificaciones reacciona instantáneamente a tu actividad y a la de otros usuarios.

- Haz clic en los perfiles de los artistas sugeridos para explorar sus galerías personales.
